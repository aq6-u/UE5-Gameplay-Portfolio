# 《明日方舟：终末地》战斗机制拆解——“庄方宜”

## 一、 核心机制与青霆剑生成公式

庄方宜的输出核心，在于将队友制造的【电磁附着】转化为【导电】，并通过战技消耗【导电】来生成【青霆剑】。

### 1. 青霆剑生成与作用机制
其战技“惊霆诀”在消耗目标导电状态时，青霆剑的生成遵循以下公式：
*   **生成数量 = 所消耗导电的异常等级 + 1**（例如：1级导电生成2柄，2级导电生成3柄）。
*   **保底机制**：若场上现存青霆剑少于3柄，即使目标无导电状态，战技也会保底生成1柄。
*   **硬性上限**：单次战技最多生成3柄；场上青霆剑总数上限为9柄，单柄存在时间约36秒。

### 2. 青霆剑的真实价值
青霆剑的数量不直接作为终结技的倍率乘区，其真实作用体现在三方面：
1.  **战技增伤**：释放战技时，会引导场上所有青霆剑依次雷击目标。剑的数量越多，战技的伤害段数越多，总倍率越高。
2.  **终结技充能**：青霆剑是庄方宜终结技能量的重要来源。
3.  **生存收益**：青霆剑能为庄方宜提供免疫伤害的生存保护。

## 二、 协同架构：连携触发与 UI 队列管理

终末地的连携技系统是这套体系运转的齿轮，其底层逻辑分为两个完全独立的阶段：

### 1. 触发阶段：条件驱动
*   **庄方宜的转化触发**：其连携“一息万变”的触发条件是主控干员的重击或处决命中处于电磁附着的敌人。注意，处决同样可以触发转化，这极大增加了战斗的操作上限。
*   **诀/佩丽卡的响应**：各自独立监听主控干员的动作或目标身上的状态。

### 2. UI 阶段：超时消失与队列补位
当一个操作同时满足多个连携条件时，UI 会按编队顺序亮起。

未释放的连携不会产生历史占位。它如果在规定时间内未被点击，会自动过期并从 UI 消失，此时队列中排在后面的连携会向上补位。这要求玩家必须在极短时间内作出决策，防止了 UI 卡死，但连携能量会保留。

## 三、 标准实战循环：以“庄+佩+诀+梨诺”为例

在该配队中，电磁附着的施加由佩丽卡与诀分担，梨诺提供增益与生存，庄方宜是唯一的导电消耗与青霆剑产出终端。

### 标准循环轴（梨诺战技起手）

1.  **梨诺战技（起手铺垫）**：释放战技“闪耀焦点”，消耗25点技力，造成电磁伤害并进入持续60秒的“演唱姿态”，为全队提供攻击力加成并周期性治疗。
2.  **挂电（佩丽卡战技）**：佩丽卡战技施加初始电磁附着（1层）。
3.  **响应（诀连携）**：敌人存在电磁附着时，触发诀的连携。施放后，诀额外施加1层电磁附着（合计2层）。
4.  **转化（庄方宜重击/处决+连携）**：庄方宜重击或处决命中，触发庄方宜连携“一息万变”。施放后，将2层电磁附着转化为2级导电。
5.  **产出（庄方宜战技）**：庄方宜释放战技，消耗2级导电，生成3柄青霆剑。
6.  **循环（资源积累）**：重复上述 1-5 步，以此循环，直至庄方宜可以开启大招前夕。
7.  **辅助（梨诺终结技）**：在爆发前夕，梨诺开启大招“晨星的协奏曲”，不仅造成伤害，还能强制给大范围敌人施加导电异常状态，直接与庄方宜体系形成强力联动。
8.  **爆发（庄方宜终结技）**：庄方宜开大，进入“天理合真”状态，开始爆发。

## 四、 终结技期间的质变

庄方宜开启终结技“万钧风雷”后（进入“天理合真”状态，约25秒），循环规则发生临时重写：

*   **首次战技特权**：不消耗技力、不消耗导电，必定生成3柄青霆剑，且额外施加1层电磁附着。
*   **连携强化**：庄方宜连携变为范围效果，且冷却恢复速度提升至4倍（约4秒一次），实现高频的“附着-导电-消耗”循环。
*   **最佳输出轴**：在终结技开启前攒至6柄剑 → 开启终结技 → 首次战技免费补到9柄（触发上限） → 随后利用高频连携与范围战技，在“天理合真”的25秒内打出满额爆发。

## 五、 UE5 GAS 架构转化

### 1. 状态 Stacking 与 UI 队列
*   **电磁/导电状态**：电磁附着用 `GE` 的 `Stacking`（上限4层）。导电用 `ExecutionCalculation` 转换，赋予 `State.Conductive.LvX` Tag。
*   **UI 补位队列**：在 `PlayerController` 中维护 `TArray<FGameplayTag> ComboQueue`。当连携条件满足，推送 Tag 进队列并给一个短 `Duration`。如果时间到未点击，通过 `Timer` 移除该 Tag，触发 UI 刷新，后面的自然补位。

### 2. 触发事件的捕获
*   **重击/处决监听**：为庄方宜的 ASC 注册对 `GameplayEvent.HeavyAttack` 和 `GameplayEvent.Execution` 的监听。收到事件时，用 `AbilityTask` 检测目标身上的 `State.Element.Electro`。

### 3. 青霆剑资源与 Buff 落地
*   **战技与伤害**：战技释放时，通过 `GetAllActorsOfClass` 获取场上所有的青霆剑 Actor。根据其数量调用对应次数的 `PlayMontage` 或 `ApplyGameplayEffect`。
*   **终结技强化**：开启终结技时，给予庄方宜 `State.Ultimate.Active` Tag。连携 Ability 的 `CanActivate` 节点判断该 Tag 存在时，强行修改 `Cooldown GE` 的时间，并将 `TargetData` 从单体改为 `SphereTrace` 范围判定。
