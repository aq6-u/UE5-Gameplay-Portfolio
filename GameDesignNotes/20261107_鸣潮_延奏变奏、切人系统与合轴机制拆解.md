# 拆解对象：《鸣潮》延奏/变奏、切人系统与合轴机制

### 一、基础信息

| 维度     | 内容                                                         |
| :------- | :----------------------------------------------------------- |
| 系统定位 | 核心战斗循环枢纽。通过多角色间的状态切换与资源传递，实现增益叠加与输出轴压缩。 |
| 核心机制 | 切人动作调度（含冷却防呆）、延奏/变奏增益传递、以及基于特定帧取消后摇的“合轴”机制。 |
| 特殊资源 | 协奏值：每个角色独立计算的底层属性（上限 100）。前台角色通过攻击/技能直接获取；后台角色依靠特殊方式间接获取。反推为独立的 `FGameplayAttributeData`。 |

### 二、切人系统状态机与底层逻辑

| 阶段             | 触发条件                 | 底层逻辑变化                                                 | 反推实现（UE5 / GAS）                                        |
| :--------------- | :----------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **普通切人**     | 协奏值 < 100，切人CD结束 | 原角色立刻中断当前逻辑退场，新角色无增益入场。               | PlayerController 切换 `Possess` 目标。原角色的 GA 被强制 `EndAbility`。 |
| **强化切人**     | 协奏值 = 100，切人CD结束 | 原角色退场触发延迟判定，新角色伴随无敌帧入场，接收原角色buff。 | 触发 `GA_OutroSkill` 与 `GA_IntroSkill`，底层同步时间轴。    |
| **切人冷却限制** | 两次切人之间存在基础CD   | 防止玩家无脑高频切人。                                       | 玩家 ASC 在切人瞬间被施加一个带有 `Cooldown.SwitchCharacter` Tag 的持续型 GE。在此 Tag 存在期间，切人 GA 处于 `Blocked` 状态。 |

### 三、核心机制底层逻辑

| 机制类型             | 底层逻辑与规则                                               | 反推实现（UE5 / GAS）                                        |
| :------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **延奏技能** (Outro) | 限定在强化切人时触发。原角色离场后，通过独立实体继续造成伤害，或为入场的新角色挂载高额增益。 | 激活 `GA_OutroSkill`。1. 通过 `SpawnActor` 生成独立的伤害检测实体。2. 调用 `ApplyGameplayEffectToTarget`，将 Buff GE 施加给即将 `Possess` 的新角色。 |
| **变奏技能** (Intro) | 限定在强化切人时触发。新角色入场时的专属动作，带有伤害判定与无敌帧。 | 新角色被 `Possess` 后激活 `GA_IntroSkill`，播放专属 Montage，挂载 `State.Invincible`。 |
| **后台协奏值**       | 角色在后台时，仍能通过特定机制获取能量资源。                 | 前台角色通过 `Send Gameplay Event`，后台角色的 ASC 监听该事件并 `Apply` 回能 GE。 |

### 四、进阶机制一：“合轴”（动作重叠）

“合轴”的本质是**“在特定帧允许打断当前动作并切人，且原角色的后续判定不消失”**。它独立于协奏能量，是底层状态机开放特定帧窗口的机制。

| 维度               | 底层机制解析                                                 | 反推实现（UE5 / GAS）                                        |
| :----------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **触发逻辑**       | 玩家在角色动作的特定帧（Cancel Window）按下切人键。          | 在动画蒙太奇特定帧添加 `AnimNotify` 开放输入窗口。窗口内切人允许跳过剩余后摇。 |
| **伤害与生命独立** | 旧角色退场，但其已释放的投射物/判定逻辑继续在场上执行 Tick。 | 技能伤害判定与角色的 `Possess` 状态解耦。`SpawnActor` 生成的实体不受 `EndAbility` 影响。 |
| **收益与风险**     | 压缩时间轴，新角色操作与旧角色后台输出重叠，抢输出与能量。   | 缩短单个角色的前台占用时间，在相同战斗时间内打出更多资源循环。 |

### 五、进阶机制二：“合轴点”的差异化设计与机制占模

并非所有动作都能合轴。合轴点的差异，取决于**动画蒙太奇中开放取消窗口的帧数长短**，以及**策划是否允许打断（强度控制）**。

| 机制分类                 | 动画与底层配置（典型案例）                                   | 设计意图（机制占模）                                         |
| :----------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **宽窗口合轴（长后摇）** | 技能释放后，有较长的后摇区间被标记为可取消窗口。例如千咲的“锯切”，在电锯动作持续期间切人，脱手判定依然保留。 | 此类角色单人站场倍率受限。通过放宽取消窗口，允许玩家用高频切人压缩轴长，以操作频率换取 DPS 上限。 |
| **精准帧合轴（短窗口）** | 仅在极短、极苛刻的特定帧开放窗口。例如穗穗只有在“重击升空、脚刚离地的瞬间”切人才能合轴。 | 将操作难度提高。即使合轴，也因为切人CD的存在，无法无脑高频触发。 |
| **无合轴点（强制站场）** | 伤害绑定在动画 `AnimNotify` 上。策划在 DataTable 关闭 `bCanSyncAction`。切人时强制 `StopMontage`，判定立刻消失。 | 针对站场倍率极高或机制完美的角色，通过底层强制关闭窗口，防止多角色合轴导致 DPS 严重溢出，强迫玩家“站场打满”以控制环境平衡。 |

### 六、整体总结与 UE5 复现方案

**系统设计核心**：
通过底层的时间轴重叠与资源传递，将输出上限转化为“多角色协同”。用**“切人CD”**作为全局防呆总闸，用**“差异化取消窗口”**作为微观操作深度，用**“机制占模（剥夺后摇取消权）”**控制宏观数值平衡。

**UE5 复现清单**：
*   **GameplayAbility (GA)**：
    *   `GA_SwitchCharacter`（切人总控，判断协奏值与切人CD）。
    *   `GA_OutroSkill` / `GA_IntroSkill`（退场与入场逻辑）。
*   **GameplayEffect (GE)**：
    *   `GE_Switch_Cooldown`（切人CD，持续挂载 `Cooldown.SwitchCharacter` Tag）。
    *   `GE_ConcourseEnergy_Add`（协奏值增加）。
    *   `GE_Outro_Buff`（退场增益）。
*   **GameplayTag**：
    *   `Cooldown.SwitchCharacter`（底层拦截切人操作）。
    *   `State.Switching`（切人动画进行中，防连按）。
*   **DataTable 配置**：
    *   `SwitchCooldownTime`（切人CD时间）。
    *   `bCanSyncAction`（决定该技能切人时是否强制 `StopMontage`，用于限制）。
