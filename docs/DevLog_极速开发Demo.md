# DevLog

>此DevLog用于记录极速开发Demo项目的每日完成进度。

## Day 1（2026.10.23）

### 完成事项

+ **玩法构思**：构思 Demo 玩法。

- **基础类搭建**：未使用官方模板。
- **属性**：在 C++ 中定义 Player 和 Boss 的血量，以及 Player 的能量。Boss 被子弹打中后会扣血。利用 PreAttributeChange 中的 FMath::Clamp 限制以上属性和功能的数值上下限。
- **委托**：使用 DECLARE_DYNAMIC_MULTICAST_DELEGATE 声明 BlueprintAssignable 委托。让数据变更时通过委托广播通知 UI。
- **输入配置**：完成 IA_Move、IA_Jump、IA_Dash、IA_Look、IA_Interact 的配置，接入 Enhanced Input。
- **参数调整**：修改 Max Acceleration 与 Braking Deceleration 参数，使角色更跟手。
- **空转修复**：在起跳时关闭 Orient Rotation to Movement，落地恢复，修复角色在空中按方向键会快速旋转的问题。
- **冲刺位移**：使用 Launch Character 配合 XYOverride 实现快速位移，且保留 0.几s 的延迟，避免一直冲刺。
- **能量球**：用立方体搭配材质。并使用 Projectile Movement 组件实现重力掉落。配置碰撞规则，实现玩家触碰自动拾取。
- **补给机关**：用立方体搭配材质。基于定时器，每 8 秒在周围随机坐标生成能量球。
- **攻击机关**：用立方体搭配材质。玩家消耗能量按 E 交互。通过 Suggest Projectile Velocity 计算抛物线轨迹，生成抛射物飞向 Boss 造成伤害。
- **攻击子弹**：用立方体搭配材质。
- **界面搭建**：制作包含玩家血条、能量条与 Boss 血条 UI。
- **数据绑定**：在 UI 构造阶段获取玩家与 Boss 引用，绑定 C++ 层的委托事件，实现界面数值刷新。
- **空中冲刺**：实测发现，空中冲刺会导致距离增加。尝试多种方案暂未解决，故暂决定封闭此功能，仅保留地面冲刺。
>**开发耗时**：约 7 h

## Day 2（2026.10.24）

### 完成事项

- **属性集拆分**：拆分 PlayerAttributeSet 与 BossAttributeSet。
- **死亡广播**：C++ 补全死亡判定，通过 BlueprintImplementableEvent 广播 OnPlayerDiedEvent 与 OnBossDiedEvent。
- **伤害管线**：废弃蓝图直接扣血，接入 GE_Damage 与 GE_Invincible。
- **UI搭建**：完成开始菜单、暂停菜单（P 键）、死亡菜单、胜利菜单及对应的输入锁死和鼠标释放。
- **UI修复**：修复战斗 UI 出现在开始界面的问题。
- **能量槽**：三段式能量槽。
- **交互提示**：攻击机关加入冷却变色与 UI「按 E」提示；满 3 格能量触发 UI「按 F」传递提示。
- **Boss陨石技能**：射线贴地生成红圈预警，延迟 1.5 秒后砸下重力方块。
- **多线并发技能**：生成 5 条平行预警线，Boss 随机挑选并发起直线冲刺方块。
- **玩家晕眩**：被方块击中后触发 StunPlayer 事件，调用 Disable Input 持续 2 秒，且变为灰色。
- **瘫痪机制**：能量满 3 格按 F 后，扣除能量并触发 Boss 瘫痪。
- **平台引用修复**：修复平台引用问题，改用 Target Point 在场地中央生成跳跃平台 C。
- **处决判定**：玩家跳跃接近晕眩 Boss 后，左键触发重击处决。
- **处决单次限制**：新增 bCanHeavyAttack 开关，仅在一次瘫痪窗口内生效一次。
- **倒计时控件**：新增控件，顶部显示 20 秒递减计数 + 下方黄色提示「Boss 将在倒计时后苏醒！并释放强力技能！」。
- **倒计时驱动**：由 Boss 端 1 秒循环 Timer 单线程驱动；归零后自动清理 Timer 与控件。
- **Boss起身技能**：冲击波判定（玩家处于 Boss 所在平台区域内则受击并被击退，击退回玩家原平台）→ 平台 C 隐藏并关闭碰撞。
- **死亡事件**：Boss 死亡事件补 Clear Timer + 隐藏倒计时。

>**开发耗时**：约 10 h

## Day 3（2026.10.25）

### 完成事项

- **行为树**：新增 BT_Boss 与 BB_Boss，通过 AIController 驱动行为树接管 Boss 逻辑。
- **自定义 BTTask**：新增自定义 BTTask_ActivateAbility与 BTTask_SelectRandomSkill。
- **随机Task**：行为树 MainLoop 实现双技能的随机调度。
- **晕眩拦截**：晕眩总闸改用 Blackboard 的 bIsStunned 键配合 Decorator 拦截，替代 Stop Logic。
- **恢复循环**：晕眩结束重置 bIsStunned 为 False，行为树恢复循环。
- **Boss起身技能**：从常规循环中移除，改为苏醒后固定释放。
- **Boss起身技能**：加入判定条件，仅当玩家与 Boss 距离 <= 3500 时触发击飞与伤害。
- **废弃跨图传值**：弃用 GameInstance 跨图传值及新关卡读取逻辑。
- **阶段转换**：Boss 血量降至 50% 时，直接在当前关卡触发环境破坏与阶段切换。
- **平台蓝图**：拆除关卡默认 Floor，新建 BP_Platform 蓝图。
- **网格化平台**：将玩家区域平台替换为 4×3 共 12 个 BP_Platform 实例。
- **深渊坠落判定**：新增高度判定逻辑，玩家 Z 轴坐标低于 -1500 时触发死亡判负流程。
- **GA_Aim 与 GA_Fire**：Q键进入全局减速并开启屏幕灰色滤镜，左键射线发射激光。
- **状态打断**：通过 GAS GameplayTag 实现开火打断瞄准状态。
- **能量上限扩展**：C++ 默认上限维持 3 格，二阶段触发时通过挂载 GE 将上限提升至 5 格，并增加对应的 UI 提示。
- **动态攻击频率**：行为树 Wait 节点改用黑板变量 AttackInterval 控制，一阶段 5 秒，二阶段砸地转场后设为 3 秒，攻击频率加快。
- **激光视觉表现**：使用 Niagara 系统，配合蓝图中的 Spawn System 与 Set Niagara Variable 实现射线激光特效。
- **倒计时文案调整**：调整瘫痪倒计时 UI 文案，提示玩家“处决完后尽快返回原平台”。
- **二阶段处决回能**：Boss 每次被处决成功后，在 Boss 位置随机爆出 1 个能量球。
- **背景与操作UI**：制作开始界面的故事背景 UI 与操作说明 UI。
- **短音效接入**：接入打击、炮击等短音效资产，处理音频导入格式问题。
- **BGM 切换逻辑**：通过存储并控制 Audio Component，在阶段转换时停止旧曲目并播放二阶段新曲目。
- **CameraShake接入**：在 Boss 砸地、处决等关键节点触发屏幕震动。
- **UI界面优化**：统一优化所有界面的视觉排版与颜色。

> **开发耗时**：约 10 h
